Términos del servicio

Última actualización: agosto de 2026.

Estos términos resumen las condiciones bajo las que se contrata y se usa Software EYO. Para el detalle de precios y planes vigentes, ver la sección de planes en la página de inicio — este documento no los reemplaza ni los modifica.

Qué se contrata

Software EYO se contrata como licencia del software configurado para el alojamiento del cliente, con la cantidad de propiedades/habitaciones y módulos incluidos según el plan elegido (Inicial, Profesional u Hotel). El pago es único por la licencia, configuración y capacitación inicial, bajo la modalidad indicada en la página de inicio: 50% para comenzar y 50% al entregar el software funcionando.

Qué incluye y qué no

  • La página web propia y el Perfil de Empresa en Google están incluidos desde el Plan Profesional (en el Plan Inicial se contratan como adicional). La aprobación y verificación del Perfil de Empresa dependen de Google, no de EYO.
  • El dominio y el hosting del sitio del cliente son servicios externos con costo propio del cliente, si corresponde.
  • El motor automático de reservas y la sincronización con Booking o Airbnb no están incluidos salvo que se contraten aparte. El sistema permite registrar de qué canal vino cada reserva, pero no sincroniza disponibilidad ni reservas automáticamente con esas plataformas.
  • El módulo de pre-facturación existe en el sistema, pero no emite comprobantes con validez fiscal (DGI) por sí solo. La facturación electrónica con validez fiscal requiere un proveedor autorizado aparte y se cotiza por separado.
  • El soporte continuo, el mantenimiento posterior a la entrega y las funciones nuevas que no estén en el alcance original se cotizan por separado.

Datos del cliente

Los datos que el cliente carga en el sistema (reservas, huéspedes, propietarios, gastos, etc.) son del cliente. EYO los aloja y los protege (ver la Política de privacidad), pero no los usa con fines propios ni los comparte con terceros. El cliente puede exportar sus datos en cualquier momento desde el panel.

Disponibilidad del servicio

El sistema corre sobre infraestructura de terceros (Supabase para la base de datos, Netlify para el hosting del panel), en sus planes gratuitos. Si bien se monitorean los límites de esos planes para no interrumpir el servicio, EYO no controla la disponibilidad de esos proveedores externos y no puede garantizar un porcentaje de actividad (uptime) determinado.

Cambios en el software

El sistema puede recibir correcciones y mejoras con el tiempo. Los cambios que afecten el funcionamiento contratado (por ejemplo, límites del plan) se comunican al cliente antes de aplicarse.
