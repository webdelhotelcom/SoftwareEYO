Política de privacidad

Última actualización: agosto de 2026.

Software EYO es un sistema de gestión para alojamientos, contratado directamente por su propietario o administrador (en este documento, "el cliente"). Esta página explica qué datos maneja el sistema y cómo se protegen.

Qué datos se guardan

Según los módulos que use cada cliente, el sistema puede guardar: datos de reservas y huéspedes (nombre, teléfono, email, documento), datos de propietarios de alojamientos, movimientos de caja y comprobantes, y los usuarios que administra cada cuenta (nombre, email, rol). No se piden ni se guardan datos de tarjetas de crédito ni medios de pago: los cobros se coordinan por fuera del sistema (por ejemplo, por WhatsApp o transferencia).

Dónde se guardan y quién puede verlos

Los datos se guardan en una base de datos real (Supabase/PostgreSQL), no en el navegador. Cada cliente tiene su información separada de la de cualquier otro cliente del sistema (aislamiento por cuenta): un cliente nunca puede ver, editar ni exportar los datos de otro cliente, esté logueado con el usuario que esté. Dentro de una misma cuenta, cada usuario ve y puede modificar solo lo que su rol tiene permitido — por ejemplo, un usuario de limpieza no puede ver ni editar datos de facturación.

Con quién se comparten los datos

Software EYO no vende ni cede los datos de ningún cliente a terceros. Los únicos proveedores externos que intervienen son los necesarios para que el sistema funcione: el proveedor de base de datos y autenticación (Supabase) y el proveedor de hosting del panel (Netlify). Ninguno de los dos accede a los datos con fines propios: solo alojan la información.

Cookies y analítica

Esta página comercial no usa cookies de seguimiento de terceros ni herramientas de analítica activas al día de hoy. El código tiene previsto un enganche para activar Google Analytics o Meta Pixel el día que se decida usarlos, pero mientras esa integración no esté cargada explícitamente, no se envía ningún dato de navegación a esos servicios. El panel de gestión usa únicamente lo necesario para mantener la sesión iniciada (cookies/almacenamiento local técnico), no con fines publicitarios.

Cuánto tiempo se conservan los datos

Los datos se conservan mientras la cuenta esté activa. Cada cliente puede exportar sus propios datos en cualquier momento (formato .json) desde el panel, y puede pedir la baja de su cuenta y el borrado de sus datos escribiendo por WhatsApp.

Registro de actividad

El sistema guarda un historial de qué usuario creó, editó o eliminó cada registro (módulo Auditoría), visible solo para el administrador de cada cuenta. Este historial es interno de cada cliente — no se comparte entre cuentas ni se usa para fines distintos de la trazabilidad de la propia operación.

Contacto

Para consultas sobre esta política o para ejercer cualquiera de los derechos mencionados arriba (acceso, exportación o borrado de datos), escribinos por WhatsApp desde la página de inicio.

Este documento describe cómo funciona el sistema realmente, sin agregar promesas que el software no cumple todavía. Si en el futuro se suma un servicio nuevo que cambie algo de lo de arriba (por ejemplo, una integración de pagos), esta página se va a actualizar antes de activarlo.
